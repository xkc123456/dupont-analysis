# 杜邦分析自动化工具

这是一份**教学示例**项目：用 Python 读取一家公司连续多年的关键财务数据，计算杜邦分析的四个比率，再用连环替代法分解相邻年份的 ROE 变动，最后导出表格和趋势图。

`data/sample_company.csv` 里的数字是**虚构的示例数据**，不代表任何真实公司，只用来把计算过程跑通、方便对照。

面向刚学会函数和 `if` 的读者。代码按步骤拆成几个短函数，注释主要写“为什么要这样做”，而不是把公式再抄一遍。

## 杜邦分析是什么

净资产收益率（ROE）衡量：股东投入的每一块钱，这一年赚回了多少。直接写法是：

```text
ROE = 净利润 / 所有者权益
```

只看这一个数字，很难知道 ROE 变高或变低是因为更赚钱、资产周转更快，还是因为杠杆更高。杜邦分析把它拆成三项：

```text
ROE = 净利率 × 总资产周转率 × 权益乘数
```

对应的公式是：

```text
净利率         = 净利润 / 营业收入
总资产周转率   = 营业收入 / 总资产
权益乘数       = 总资产 / 所有者权益
ROE            = 净利润 / 所有者权益
```

把中间三项乘开，营业收入和总资产可以约掉，结果应等于直接计算的 ROE。本工具会自动做这个核对。若对不上，优先检查公式，而不是先怀疑数据“算得不够精确”（程序里允许的误差非常小）。

三个因子可以粗浅地这样理解：

- **净利率**：卖出的每块钱里，留下多少利润（盈利能力）
- **总资产周转率**：一块钱资产能撑起多少收入（营运效率）
- **权益乘数**：资产相对股东权益有多大（财务杠杆）

## 计算口径

### 平均余额还是期末余额

总资产和所有者权益在一年里会变动。用哪一个数字当“这一年的余额”，会改变周转率、权益乘数和 ROE。

- **平均余额（默认）**：`(期初 + 期末) / 2`。更接近这一年真正占用的资源。
- **期末余额**：只用期末数。计算更简单，但忽略年内变化。

命令行用 `--basis average` 或 `--basis end` 切换。营业收入、净利润始终用当年发生额，不存在“平均还是期末”的问题。

两种口径算出来的数字通常不一样。这不是程序出错，而是分析起点不同。写报告时把口径写清楚即可。

### 连环替代法，以及为什么顺序会影响分摊

要解释“ROE 比去年高了（或低了）多少，分别来自哪个因子”，本工具使用连环替代法：一次只换一个因子，把这一段变化记在刚刚被换掉的因子头上。

替代顺序固定为：

1. 先把**净利率**换成今年，周转率和权益乘数仍用去年
2. 再把**总资产周转率**换成今年，权益乘数仍用去年
3. 最后把**权益乘数**换成今年

若去年记为下标 0、今年记为下标 1，三项贡献是：

```text
净利率贡献         = A1×B0×C0 − A0×B0×C0
总资产周转率贡献   = A1×B1×C0 − A1×B0×C0
权益乘数贡献       = A1×B1×C1 − A1×B1×C0
```

三项加起来等于今年 ROE 减去年 ROE。

**顺序会影响“每个因子摊到多少”，但不会影响三项合计。**  
后被替代的因子，会乘上已经换成“今年”的前面因子。如果改成先换权益乘数、再换净利率，交叉影响会被算进不同的因子，于是每个贡献的数字会变；但三段变化仍然首尾相接，加总还是那个总变动。所以比较两份分解结果时，要先确认替代顺序是否相同。本工具不提供改顺序的开关，是为了让第一次学习时口径保持稳定。

## 如何安装和运行

在项目根目录（本 README 所在的文件夹）打开终端。建议先建一个虚拟环境，再安装依赖（这样不会改动系统自带的 Python）：

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python main.py
```

如果当前环境已经能直接安装第三方库，也可以跳过前两行，改用 `python3 -m pip install -r requirements.txt`，然后运行 `python3 main.py`。

默认会读取 `data/sample_company.csv`，按**平均余额**计算，并在 `output/` 下写出：

- `output/dupont_ratios.csv`：各年比率表
- `output/dupont_decomposition.csv`：相邻年份的连环替代分解表
- `output/dupont_trends.png`：ROE 与三个因子的趋势图

两个 CSV 使用 `utf-8-sig` 编码，方便在 Excel 里直接打开中文列名。

常用参数：

```bash
# 改用期末余额
python3 main.py --basis end

# 指定自己的数据文件和输出目录
python3 main.py --input data/sample_company.csv --output-dir output
```

运行测试：

```bash
python3 -m pytest -q
```

如果输入缺列，或营业收入、总资产、所有者权益不是正数，程序会用中文说明问题并退出，不会继续写出一份不可靠的结果。净利润可以是负数（亏损），这时净利率和 ROE 也会是负数。

## 输入文件格式

CSV 需要包含下面这些列（英文列名，不要改写）：

| 列名 | 含义 |
| --- | --- |
| `year` | 年份 |
| `revenue` | 营业收入 |
| `net_profit` | 净利润 |
| `total_assets_begin` | 总资产期初 |
| `total_assets_end` | 总资产期末 |
| `equity_begin` | 所有者权益期初 |
| `equity_end` | 所有者权益期末 |

以 `#` 开头的行会被当作注释忽略。示例文件开头就用注释标明了“这是虚构数据”。

## 文件地图

```text
dupont-analysis/
  main.py                 程序入口，负责读参数、把各步骤串起来
  requirements.txt        需要安装的第三方库
  data/sample_company.csv 虚构的五年示例数据
  dupont/loader.py        读 CSV，检查缺列和非法分母
  dupont/ratios.py        计算四个比率，并核对三因素乘积
  dupont/decompose.py     连环替代法分解相邻年份
  dupont/report.py        写出 CSV 和趋势图
  tests/                  基本的公式和报错测试
  output/                 运行后生成的结果（可反复覆盖）
```

## 建议阅读顺序

如果你是第一次看这份代码，可以按下面的顺序读：

1. 本 README：先弄清要算什么、口径是什么
2. `data/sample_company.csv`：看输入长什么样
3. `main.py`：看程序从哪里开始、先做什么后做什么
4. `dupont/loader.py`：数据是怎么读进来、怎么被拒绝的
5. `dupont/ratios.py`：四个比率和恒等核对
6. `dupont/decompose.py`：连环替代的三步
7. `dupont/report.py`：表格和图片怎么生成
8. `tests/`：用具体数字检查公式有没有写错

## 已知限制

- 只支持一家公司、一个 CSV。多公司需要先拆成多个文件，分别运行。
- 连环替代的因子顺序是固定的，不能在命令行里改。
- 趋势图需要本机有可用的中文字体（例如 Noto Sans CJK）才能显示中文标题；找不到中文字体时会自动改用英文标签，不会因此崩溃。
- 这是教学工具，不处理完整报表、合并抵消、异常值修复或审计校验。
